# Macropolo Infra Solution website

This is a static, responsive website. It runs without a paid builder, database, or server. Keep `index.html`, the logo, all three `.avif` site photos, and all three director portraits in the same folder. Open `index.html` in a browser to preview it.

The logo and construction photos are local copies, so the published site does not depend on the Base44 page remaining online.

The team section uses the supplied portraits for Amit Tiwari, Manish Khare and Ritesh Rai. The short bios identify each as a director without adding career details that were not supplied.

## Free hosting with your own domain

GitHub Pages can host the site at no hosting charge from a public repository on GitHub Free. You can connect a domain you own; domain registration itself may have a separate fee.

1. Create a GitHub account and a public repository for this site.
2. Upload all files from this folder to the repository root.
3. In **Settings → Pages**, publish from the `main` branch and root folder.
4. Add your domain in Pages settings, then configure the DNS records shown there with your registrar. Use the exact records GitHub provides for your selected hostname.
5. Once DNS is active, enable HTTPS in Pages settings.

GitHub's current documentation: [About custom domains and GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages) and [Managing a custom domain](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## Inquiry form

The form opens a draft email addressed to `info@macropolo.in` with the entered details. It does not send automatically. If a BOQ is selected, attach it to the draft manually before sending. Direct file uploads require a server or a separate form service.
